# 05. Примеры работ и галереи

## Начало страницы

Добавить короткое вступление и кнопки-якоря:
- Витрина памятников
- Благоустройство
- Изготовление памятника
- Наша гравировка

## Блок 1. Витрина памятников

Категории:
1. Одиночные памятники
2. Двойные памятники
3. Мемориальные комплексы
4. Эксклюзивные работы

Карточка памятника:
- фото;
- название;
- материал;
- краткое описание;
- маленькая кнопка «Добавить в избранное» в виде звёздочки;
- открытие модального окна;
- без цен;
- без меток.

## Модальное окно памятника

Показывает:
- фото;
- название;
- категорию;
- материал;
- описание;
- кнопку «Добавить в избранное»;
- кнопку «Заказать расчёт»;
- кнопку «Позвонить».

Предупреждение о стоимости не показывать.

## Блок 2. Благоустройство

Отдельный блок с обычной галереей. Без формата «до / после».

## Блок 3. Наши работы по изготовлению памятника

Одна карточка показывает:
1. Эскиз
2. Готовый камень
3. На кладбище

## Блок 4. Наша гравировка

Одна широкая карточка:
- ретушь;
- на памятнике;
- описание;
- кнопка «Добавить в избранное»;
- кнопка «Заказать памятник на странице заявки».

Автоматический выбор типа обращения оставить на будущее.

## Единый просмотр изображений

Компонент используется для:
- памятников;
- услуг;
- благоустройства;
- изготовления памятника;
- гравировки;
- отзывов;
- слайдера офиса.

Функции:
- открыть по нажатию;
- затемнить фон;
- закрыть по крестику;
- закрыть по клику вне изображения;
- закрыть по Esc;
- показать подпись;
- листать изображения, если их несколько.

Кнопку «Добавить в избранное» в просмотре показывать только для памятников.

## Фильтры

В первой версии фильтры не делать. Запланировать на будущее.
