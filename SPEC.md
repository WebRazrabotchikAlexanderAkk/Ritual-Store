# План сайта ритуальных услуг

Комплект документации для первой версии сайта существующей компании ритуальных услуг.

## Цель первой версии

Сайт должен работать 24/7 и помогать посетителю быстро:
- найти телефон компании;
- изучить услуги;
- посмотреть примеры работ;
- оставить заявку на расчёт;
- добавить понравившиеся памятники/работы в избранное;
- ознакомиться с документами, FAQ, отзывами и контактами.

## Технический стек

- React
- Vite
- JavaScript
- Material UI
- React Router
- localStorage
- Отправка заявок в Email / Telegram / MAX
- Без админ-панели, базы данных, регистрации и личного кабинета
