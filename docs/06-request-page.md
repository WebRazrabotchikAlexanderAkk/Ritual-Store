# 06. Страница заявки

## Назначение

Клиент может оставить телефон, приложить фото, выбрать услуги и отправить заявку на расчёт.

Заявка отправляется в:
- Email компании;
- Telegram;
- MAX.

## Структура формы

Форма на одной странице, но разделена на блоки.

### Тип обращения

Множественный выбор:
- Изготовление памятника
- Установка памятника
- Гравировка
- Благоустройство
- Уход за захоронением
- Ритуальные товары
- Доставка и монтаж
- Другое

У каждого выбранного элемента кнопка «Убрать».

### Контактные данные

- ФИО
- Телефон
- В каком вы городе

Обязателен только телефон.

### Телефон

Сверху выбор:
- RU номер
- Другой

RU номер форматируется автоматически:
> +7 (999) 123-45-67

Для иностранного номера отдельное поле без российской маски.

### Место работ

- Адрес кладбища
- Примерное описание места захоронения
- Фото

### Детали заказа

- Желаемый дедлайн
- Комментарий
- Дополнительные фото

### Выбранные варианты

Элементы из избранного можно отправить вместе с заявкой. На странице заявки каждый элемент можно убрать из заявки, не удаляя из избранного.

### Согласие

Обязательный чекбокс:
> Я согласен на обработку персональных данных

Ссылка открывает PDF политики в новой вкладке.

## Файлы

Только изображения:
- JPG / JPEG
- PNG
- WEBP
- возможно HEIC

Ограничения:
- до 30 изображений;
- до 100 МБ на одно изображение.

Фото после обновления страницы не сохраняются.

Предупреждение:
> После обновления страницы прикреплённые фото нужно будет выбрать заново.

## Предупреждение при уходе

Если пользователь заполняет форму и уходит со страницы:
> Вы заполняете заявку. Если уйти со страницы, прикреплённые фото могут быть потеряны.

## Проверка перед отправкой

Перед отправкой показать окно проверки:
- типы обращения;
- ФИО;
- телефон;
- город;
- адрес кладбища;
- дедлайн;
- количество фото;
- количество выбранных элементов;
- комментарий.

Кнопки:
- Отправить заявку
- Вернуться к редактированию

## После отправки

- форма остаётся заполненной;
- данные хранятся в localStorage;
- кнопка отправки неактивна до изменения формы;
- показывается время последней отправки;
- показывается блок благодарности.

Благодарность:
> Спасибо, заявка отправлена. Специалист свяжется с вами по указанному номеру для уточнения деталей.

В блоке:
- график работы;
- кнопка «Позвонить сейчас»;
- кнопка «Создать новую заявку».

## Повторная отправка

Если пользователь уже отправлял заявку:
> Вы уже отправляли заявку. После повторной отправки прошлая заявка будет считаться неактуальной.

## Очистка

Кнопка «Очистить форму заявки» с подтверждением.

Кнопка «Создать новую заявку» с подтверждением.
