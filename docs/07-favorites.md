# 07. Избранное

## Назначение

Пользователь может сохранять понравившиеся памятники и работы без регистрации.

## Хранение

Избранное хранится в браузере через localStorage.

Ключ:
```js
ritual-services-favorites
```

## Иконка в шапке

Иконка — звёздочка. Если есть элементы, показывается красный кружок с цифрой.

При нажатии — переход на страницу «Избранное».

## Страница «Избранное»

Элемент содержит:
- фото;
- название;
- категорию;
- описание;
- кнопку «Удалить»;
- чекбокс «Добавить к заявке».

## Очистка

Кнопка «Очистить избранное» с подтверждением:
> Вы уверены, что хотите очистить избранное?

## Выбор для заявки

Пользователь отмечает галочками только нужные элементы и нажимает:
> Отправить выбранное в заявку

Выбранные элементы сохраняются отдельно:
```js
ritual-services-request-selected-items
```

## Единый объект избранного

```js
{
  id: 'single-monument-01',
  type: 'monument',
  title: 'Одиночный памятник 01',
  category: 'Одиночные памятники',
  description: 'Краткое описание памятника.',
  image: '/images/monuments/single/single-monument-01.webp',
  sourcePage: '/works'
}
```
