# 03. Главная страница

## Структура

1. Первый экран.
2. Блок «О компании».
3. Блок «Этапы работы».
4. Блок карточек-переходов.
5. Кнопка «Заказать расчёт».

## Первый экран

- большое изображение примерно на 3/5 ширины экрана;
- название компании;
- краткое описание;
- телефон;
- кнопка «Позвонить»;
- фраза о памятниках, гравировке и благоустройстве.

## Блок «О компании»

В блоке описать:
- чем занимается компания;
- большой ассортимент;
- эксклюзивные заказы любой сложности;
- индивидуальный подход к заказу и клиенту;
- почему клиент получает больше при работе с компанией.

Фраза для блока:

> Почему клиент получает больше при работе с нашей компанией

## Документы в блоке «О компании»

Оставить место под:
- Политику обработки персональных данных;
- Реквизиты компании;
- Условия нашего договора;
- Образец нашего договора.

## Блок «Этапы работы»

Расположение: после блока «О компании».

Этапы:
1. Обращение клиента.
2. Уточнение деталей.
3. Подбор решения.
4. Согласование заказа.
5. Выполнение работ.
6. Завершение заказа.

Этапы интерактивные: при нажатии раскрывается подробное описание. Кнопку в конце блока не добавлять.

## Карточки переходов

Карточки с иконками:
- Услуги
- Примеры работ
- Заявка
- Контакты

Ниже кнопка:
- Заказать расчёт
