# 02. Структура страниц

## Основные страницы

1. Главная
2. Услуги
3. Отдельные страницы услуг
4. Примеры работ
5. Заявка
6. Избранное
7. Документы
8. Вопросы и ответы
9. Отзывы
10. Контакты
11. Страница 404

Отдельной страницы «О компании» не будет. Достаточно блока «О компании» на главной.

## Меню

Порядок пунктов меню:
1. Главная
2. Услуги
3. Примеры работ
4. Заявка
5. Документы
6. Вопросы и ответы
7. Отзывы
8. Контакты

## Общая логика

- Главная не перегружается примерами работ.
- Услуги ведут на отдельные страницы услуг.
- Примеры работ разделены на крупные блоки.
- Заявка на одной странице, но разделена на блоки.
- Избранное работает без регистрации.
- Документы открываются/скачиваются из отдельной страницы.
- FAQ — общий список без категорий.
- Контакты содержат базовую информацию и слайдер офиса.
